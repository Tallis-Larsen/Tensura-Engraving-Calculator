# Tensura-Engraving-Calculator
A simple C++ FTXUI app to calculate the probabilites of getting each engraving in the Tensura: Reincarnated Minecraft mod. This exists because I was bored this weekend.

The build system is setup for Linux only. If someone actually wants to use this and is on Windows, please make an issue.
